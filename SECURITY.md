# Security Policy and Liability Disclosure

## Supported Versions
At this time, only the `main` branch is actively supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| main    | :white_check_mark: |
| older   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within this project, please refrain from disclosing it publicly. Instead, contact the maintainers directly by opening an issue labeled `SECURITY` or reaching out through official CYB3R8 channels for a private disclosure. We will make every effort to acknowledge and address reports promptly.
